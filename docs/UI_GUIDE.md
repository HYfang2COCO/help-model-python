结果曲线可选择起止日期，并按日、月、年显示。月／年按选中日期内的日水量求和；逐层表按同一日期筛选。完整汇总和下载仍保留全时段数据。

### 层编辑

单击层表中的任意单元格选择该层，蓝色行是当前选择；下方可直接移动、删除或编辑。降水可从CSV/Excel导入，也可粘贴；选择列和单位后先核对预览。

“计算方法与植被设置”提供新公式模块，详见随包 `docs/V22_METHODS.md`。以下段落中固定CN、外部PET和经验膜闸门描述的是旧版兼容模式。

在“配置剖面”中新增所需类型，选中层后上移、下移、删除或编辑。每层参数独立。更换类型重置该层参数，编辑完成后点“保存此层参数”。全局设置也须保存。重排保持稳定 id，删除回灌目标会关闭回灌。

孔隙率、田间持水量、萎蔫点、初始含水量均为体积分数（0～1），厚度单位 mm，导水率 mm/day。要求 WP < FC < 孔隙率。膜层无孔隙储水，不填写含水量；膜等效Ks和泄漏倍率是经验输入，不能等同官方材料参数。

JSON可从侧栏导入、导出。layers数组从上到下；复制样例可作为新模板。气象表需要 date、precip_mm、temp_c、pet_mm 四列，逐日连续。

### 结果解释

所有 mm 为场地面积上的水深，1公顷上 1 mm = 10 m³。逐层表按 layer_id 区分覆盖导排、渗滤液收集和泄漏检测用途。多层净收集之和是界面总收集量。中间膜穿透量是内部转移，不能与底部外流重复相加。

bottom_leakage 是越过剖面最底边界的外流，无衬垫时是自由排水。liner_leakage 是同一项的兼容名称。回灌在次日注入，未注入前仍计入系统储量；超容量拒收记作外排径流。

### 近似范围

本程序不是 EPA HELP 官方算法。固定CN、度日融雪、限水ET、局部水头、简化Darcy侧向流和经验膜闸门均存在简化。水量平衡闭合不等于预测准确。没有冻土、植被生长、针孔缺陷、膜土接触、优先流、污染物运移和实测校准。

允许自由排列仅表示程序能够计算，并不表示符合EPA层序规则或工程合理。结果仍受子步数、层划分及参数选择影响。详见随包 README 和 TECHNICAL_NOTES。
